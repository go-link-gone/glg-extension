# GoLinkGone Extension

A compact browser extension for GoLinkGone that keeps shortening and URL flow close at hand.

## What it does

GoLinkGone provides a lightweight popup experience for working with short links from the browser.

## How to use

1. Load the extension in your browser from the extension folder.
2. Open the popup from the toolbar icon.
3. Use the available controls to work with GoLinkGone links.

## Included files

The extension ships with the popup interface, the extension manifest, and icon assets in multiple sizes for browser compatibility.
